# 🧮 Apple-Inspired Calculator

A responsive web calculator built with vanilla HTML, CSS, and JavaScript as part of **The Odin Project** Foundations curriculum. The UI replicates the dark-mode aesthetic of the iOS calculator.

## 🚀 Live Demo

https://narukanaveen.github.io/calculator/

## ✨ Features

- **Math Operations**: Addition, subtraction, multiplication, and division
- **Operator Chaining**: Evaluates pairs consecutively without needing `=` between steps[cite: 1].
- **Edge-Case Handling**:
  - Division by zero safety check
  - Prevents multiple decimal points
  - Rounds long decimal results to prevent display overflow
  - Clean state reset when typing new numbers after pressing `=`.
- **iOS Theme**: Dark palette, circular keys, pill-shaped action buttons, and active press animations

## 🛠️ Built With

- HTML5
- CSS3 
- Vanilla JavaScript
